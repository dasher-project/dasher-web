# Changelog

## v0.2.0 (2026-08-30)

- Language selector expanded from 27 to 90 languages — all languages with
  real training data in DasherCore v0.2.14+ (Tatoeba CC-BY corpora from
  WorldAlphabets), plus Chinese (Simplified) and Hindi retained from v0.1.0
- Language entries now carry script name and RTL metadata; list is sorted
  alphabetically with English as the default
- Banner linking to the Dasher v6 alphabet catalogue (474 alphabets, 456
  languages) and the app downloads page
- Version bumped to 0.2.0 to align with DasherCore v0.2.x

## v0.1.0

- Initial public release of the Dasher Six web demo
- Pure JS implementation (PPM predictor, no WASM required)
- 26 languages with alphabets and lexicons
- Mobile-safe stacking
